DRAFTS
======

Drop your handwritten article drafts in this folder as .txt files.
Anything in here is IGNORED by the Astro build (it only reads src/content/blog),
so you can write freely without breaking anything.

When a draft is ready, tell Claude and it will:
  - format it into clean Markdown
  - add the frontmatter (title, description, tags, image, etc.)
  - create the real post at src/content/blog/<slug>.md
  - spin up a local preview for you to approve

Format: just write naturally. You don't need Markdown — plain text is fine.
A loose structure that helps:

  TITLE: <your headline>

  <your article body, however you like to write it>

See _template.txt for an example you can copy.
